FIHAY FRMS v1.0 PILOT

About this system

FiHay Farm Record Management System is a field-first pilot for production, finance, livestock, inventory, incidents and farm knowledge. It is built for one farm per installation during the pilot, with Farm IDs and master data structured so the design can later evolve into a multi-farmer BAM rollout.

The current release is mobile-friendly and can operate without internet when the device can reach the local farm server. FiHay AI Help uses local records and the knowledge base only; it does not send farm data to an external AI provider.

Before a wider or public-cloud rollout, the next production layer should add user accounts, farmer-level permissions, secure central synchronization, audit logs and formal backup/restore administration.
